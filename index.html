ParlCent React Map Demo

This is a simple interactible React web app that replicates the world map on the home page of the Parliamentary Centre.
It reads a CSV dataset to paint each region a distinct color according to how it looks on the site, and hovering over a country will show a popup leading to the organization's programs in that region.
Components used:

  • React app built with Vite
  • Map rendered with React Simple Maps, using a dataset from Kaggle.
  • Tooltips made with React Tooltip
